`pg_validate` is a pure SQL extension for Postgres 16, 17 and 18. Each validator takes a `text` value and returns a boolean, so it works in `CHECK` constraints, domains and queries. Built-in validators are `IMMUTABLE STRICT PARALLEL SAFE`, and the markings are true.

Read the [overview](./overview/) for what the extension checks, and what no validator can check: a valid email address can still be undeliverable.

## Register your own formats

The [format registry](./guides/custom-formats/) names every validator, so `validate.format('email', value)` works, and lets trusted roles add their own. Custom validators run with the caller's privileges.

## Validate JSON documents

[`validate.json_schema(doc, schema)`](./reference/json-schema/) checks `jsonb` against JSON Schema Draft 2020-12 in PL/pgSQL, with `format` asserted through the registry, so your custom formats work in schemas too. It passes the official JSON Schema Test Suite apart from documented exceptions.

The [roadmap](./plans/roadmap/) lists candidate formats.
