## What it is

`pg_permissions` is an authorization extension written in pure SQL. One schema supports several permission models: RBAC
today, Zanzibar/FGA-style relationships (sharing, nested teams, parent inheritance), and attribute rules later. Policies
call it from inside row-level security, so the database enforces access, not the app.

## The three engines at a glance

<EngineCards />

The headline: RBAC is a wash, with every engine within about 0.2 ms. The choice only matters once an app graduates to
per-object sharing, where the engines trade read cost against nesting cost and complexity.
