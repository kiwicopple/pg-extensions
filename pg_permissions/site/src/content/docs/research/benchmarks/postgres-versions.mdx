Do the designs behave in the same way on different Postgres major versions? This page shows every version that exists in
the benchmark data. Each run file has a `pg_version`, an `environment` and an optional `tag`. A series is one major version on one
environment with one tag. The page compares versions only within the same environment and tag. The optimized designs (tag `opt`) come first,
and the runs before the optimizations follow.

The [Postgres versions report](../versions-report/) has the Docker analysis. [Optimizations](../optimizations/) shows the effect of
the optimization pass. The [benchmarks dashboard](../dashboard/) describes the workloads and the charts.
