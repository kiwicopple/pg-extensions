`pg_idkit` provides five ID generators and a UUIDv7 timestamp extractor in SQL and PL/pgSQL, without pgcrypto or compiled code. These docs cover version 0.0.5.

UUID and KSUID generators use Postgres `random()`; ULID uses strong randomness from the built-in UUIDv4 generator. IDs are not secrets. Keep a primary key for uniqueness and a separate timestamp for application dates.
