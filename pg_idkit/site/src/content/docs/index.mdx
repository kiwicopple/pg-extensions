`pg_idkit` provides four ID generators and a UUIDv7 timestamp extractor in SQL and PL/pgSQL, without pgcrypto or compiled code. These docs cover version 0.0.4.

IDs use Postgres `random()` and are not secrets. Keep a primary key for uniqueness and a separate timestamp for application dates.
