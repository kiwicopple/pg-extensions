`pg_crdt` is a SQL and PL/pgSQL extension for Postgres 16, 17 and 18. A CRDT is a value that several writers can change independently and merge later, in any order and any number of times, and still agree on the result. Version 0.0.1 has one type, the PN-Counter: a counter that goes up and down, where every writer keeps its own running totals.

It works with any client, driver or API layer, needs no superuser and no C, and assumes no identity provider. Read the [overview](./overview/) for what a CRDT gives you, and when a plain column is the better choice.

## One rule

Merge in the statement that writes: `update posts set likes = crdt.pn_merge(likes, $1) where id = $2`. Never read the state, merge it in your application and write the result back. See [Update safely](./guides/safe-updates/).

The PN-Counter is the only type so far. Sets, registers, maps and text are planned: see the [overview](./overview/#the-types).
