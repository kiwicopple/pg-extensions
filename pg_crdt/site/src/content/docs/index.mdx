`pg_crdt` provides counters and experimental plain-text columns that merge independent changes. It runs on Postgres 16, 17 and 18, uses SQL and PL/pgSQL, and works with any database driver. Start by [installing the extension](./install/).

## Choose the right workload

Counters cannot enforce strict bounds across disconnected writers. Text columns rewrite their whole state on every edit and retain deletion metadata. Large documents and frequent edits may need a different design. Read [what pg_crdt does](./overview/) and the [text limitations](./text/limits/) before adopting it.

Table-backed documents and their client are separate research. The active extension keeps state in your own columns and installs no document tables.
